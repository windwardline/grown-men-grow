# Bluesky

## Post 1

Anybody who's put a spare on in a driveway knows the urge to run the first nut all the way down before touching the others. Run it down first and the wheel can seat a hair crooked. Nothing looks wrong. The car drives fine for a month.

## Post 2

Braking for an exit, the pedal starts to pulse and the steering wheel does a small shimmy. That's the rotor, clamped unevenly back in the driveway. People blame the rotors. The rotors were just standing closest.

## Post 3 — canonical link

Sometimes the only way to seat the wheel is to back the first nut off. Not off. Off a turn. Nobody gets a trophy for loosening something. [canonical link]

# LinkedIn Page

Any shop manual gives the order for lug nuts. Start every one by hand, snug them in a star, then tighten them in the same star, in passes, so the wheel comes down flat on the hub from every side at once.

The new field note is about the man who runs one nut all the way down first, usually a good one, and finds the rest have seated crooked around it. It's straight about what fixing that can cost, and about the seasons when there's no garage, only a shoulder in the rain. [canonical link]
