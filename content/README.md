# Approved Public Content

This directory receives only founder-approved public copy and production assets.

- `ghost/` holds the approved Start Here page, About page, welcome email, and launch-essay source files.
- `instagram/` holds the approved launch package; rendered platform assets live under `assets/drafts/` until posting is authorized.
- `field-notes/` holds approved cross-surface editorial packets whose publication timing or final artwork remains pending.
- `distribution/` holds reviewed platform adaptations and channel-specific metadata. A file's frontmatter records whether its exact copy is approved for posting.

Do not copy the confidential reputation addendum, private evidence, credentials, account exports, or unapproved drafts into this directory.
